## Getting Started

### Prerequisites

- Node.js
- npm, pnpm, or Bun

### Installation

Clone the repository:

```bash
git clone https://github.com/yemizerfe/yemisrach-portfolio.git
```

Navigate into the project:

```bash
cd yemisrach-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.
